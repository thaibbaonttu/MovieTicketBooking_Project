## Giới thiệu dự án:
Website bán vé xem phim trực tuyến giúp khách hàng
xem danh sách phim, lựa chọn suất chiếu và đặt vé.

## Chức năng chính:
- Xem danh sách phim.
- Xem thông tin chi tiết phim.
- Tìm kiếm phim.
- Đặt vé xem phim.
- Đăng nhập và đăng ký.
